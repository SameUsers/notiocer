# Автоматическая рассылка счетов

Приложение формирует и отправляет письма с перечнем счетов, для которых не
получена предоплата до загрузки. Источник данных — Excel-отчёт; данные
получателей сотрудников загружаются из Microsoft Dynamics AX через ODBC, а
письма отправляются через Microsoft Exchange.

## Как работает приложение

1. Читает первый лист Excel-отчёта и сопоставляет заголовки колонок с полями
   счёта.
2. Отбирает счета разрешённых категорий, выставленные не менее чем за заданное
   число дней до запуска и удовлетворяющие условию предоплаты.
3. Определяет получателей по платёжному сервису и рынку счёта: для части
   сервисов адрес задан фиксированно (общий почтовый ящик), для остальных
   получателем становится ответственный сотрудник из счёта. Логика
   маршрутизации реализована в
   `src/domain/services/recipient_mailing_list_builder.py`.
4. Формирует отдельное письмо для каждого получателя с Excel-вложением
   `invoices.xlsx`.
5. Закрывает загруженную книгу после завершения обработки. Адреса сотрудников
   кэшируются в `data/user_cache.json`.
6. При необходимости запускает макрос QlikView через внешний исполняемый файл
   (адаптер `QlikViewMacrosRunner`).

## Структура проекта

- `main.py` — точка входа и сборка зависимостей приложения.
- `requirements.txt` — зафиксированные зависимости проекта.
- `src/domain/` — сущность счёта и правила отбора, группировки (включая
  маршрутизацию по получателям) и подготовки сообщений.
- `src/application/` — сценарий обработки отчёта и порты взаимодействия.
- `src/controllers/` — чтение локального файла и запуск сценария.
- `src/infra/` — адаптеры к внешним системам и настройки приложения:
  - `ax_adapters/` — поиск email сотрудников в Microsoft Dynamics AX;
  - `excel_readers/` — чтение счетов из `.xlsx` (openpyxl) и `.xls` (xlrd);
  - `excel_writers/` — сборка Excel-вложений (openpyxl);
  - `exchange_adapters/` — отправка писем через Microsoft Exchange;
  - `subprocess_adapters/` — запуск внешних процессов (`QlikViewMacrosRunner`);
  - `settings.py` — настройки приложения (pydantic-settings).
- `src/utils/` — вспомогательные утилиты (декоратор `retry_sync`).
- `sql/` — SQL-запрос для поиска адреса сотрудника в Dynamics AX.
- `workdir/` — каталог для локального входного отчёта по умолчанию.

## Требования

- Python 3.12 или новее.
- Доступ к Microsoft Dynamics AX и Microsoft Exchange.
- ODBC-драйвер для SQL Server, соответствующий настройке `AX__ODBC_DRIVER`
  (по умолчанию используется `ODBC Driver 17 for SQL Server`).
- Системная библиотека `unixODBC` для `pyodbc` (на macOS устанавливается через
  `brew install unixodbc`; после установки `pyodbc` может потребоваться
  переустановка из исходников: `pip install --no-binary :all: pyodbc`).
- QlikView (если используется запуск макросов через `QlikViewMacrosRunner`) —
  путь к исполняемому файлу задаётся при создании адаптера.

## Установка зависимостей

Зависимости зафиксированы в `requirements.txt`. Установка в виртуальное
окружение:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Настройка

Настройки читаются из переменных окружения и файла `.env` в корне проекта.
Вложенные параметры разделяются через `__`; имена переменных чувствительны к
регистру. Значения окружения имеют приоритет над значениями по умолчанию.

Пример `.env` (укажите собственные значения; не добавляйте реальные пароли в
репозиторий):

```dotenv
AX__ODBC_DRIVER=ODBC Driver 17 for SQL Server
AX__SERVER=<имя-сервера>
AX__DATABASE=<имя-базы>
AX__USERNAME=<пользователь>
AX__PASSWORD=<пароль>

EXCHANGE__USERNAME=<учётная-запись>
EXCHANGE__PASSWORD=<пароль>

INVOICE_REPORT_FILE__PATH=workdir/DZ_Report.xls
```

Путь к отчёту по умолчанию — `workdir/DZ_Report.xls`. По умолчанию для отбора
используются категории `Д0`, `Д1`, `Д2`, `Д3`, `Д4`, `Д5`, `Д60` и минимальный
возраст счёта в три дня. Категории и возраст можно изменить в настройках
`INVOICE_SELECTION__ALLOWED_CATEGORIES` и
`INVOICE_SELECTION__MINIMUM_INVOICE_AGE`.

Заголовки входного отчёта должны соответствовать используемым приложением
названиям колонок, например `ID клиента`, `Полный номер счета`, `Дата счета`,
`Категория`, `Сотрудник` и `Сервис для срока оплаты`. Поддерживаются оба
формата: `.xls` (через `XlrdInvoiceReader`) и `.xlsx` (через
`OpenpyxlInvoiceReader`); выбор адаптера определяется настройкой или типом
файла — см. `main.py`.

## Запуск

Из корня проекта после установки зависимостей и настройки окружения:

```bash
python main.py
```

Для Exchange включён autodiscover. Перед рабочим запуском убедитесь, что
учётная запись имеет необходимые права, AX доступен по ODBC, а входной отчёт
существует и содержит корректные заголовки.

Если используется запуск макросов QlikView, убедитесь, что QlikView установлен,
а путь к исполняемому файлу и таймаут заданы корректно при создании
`QlikViewMacrosRunner`.
